# React Starter Kit

Laravel with React, Inertia, TypeScript, Tailwind CSS and shadcn/ui. It comes with login (registration, password reset, email verification, two-factor authentication, passkeys), a dashboard and settings for profile, password and appearance.

A copy of [laravel/react-starter-kit](https://github.com/laravel/react-starter-kit), made for [Mosaic for Laravel](https://github.com/Zomt3c/mosaic-laravel).
