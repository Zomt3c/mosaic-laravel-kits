# Mosaic for Laravel Kits

React starter kits for [Mosaic for Laravel](https://github.com/Zomt3c/mosaic-laravel), based on Laravel's official starter kits.

| Kit | What it is | Based on | Laravel commit |
|---|---|---|---|
| `react-starter-kit` | Login, dashboard and settings | [laravel/react-starter-kit](https://github.com/laravel/react-starter-kit) | `360a762` |
| `react-starter-kit-blank` | No login, only a welcome page | [laravel/blank-react-starter-kit](https://github.com/laravel/blank-react-starter-kit) | `804562b` |
