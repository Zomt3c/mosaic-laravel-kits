# React Starter Kit (blank)

Laravel with React, Inertia, TypeScript and Tailwind CSS, without login and without UI components. It only has a welcome page.

A copy of [laravel/blank-react-starter-kit](https://github.com/laravel/blank-react-starter-kit), made for [Mosaic for Laravel](https://github.com/Zomt3c/mosaic-laravel).
